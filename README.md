# Random Password Generator (Генератор случайных паролей)

## Автор
Иван Иванов

## Описание
Генератор случайных паролей с графическим интерфейсом на Python. Приложение позволяет создавать безопасные пароли с настройкой параметров и сохраняет историю генерации.

## Возможности
- Настройка длины пароля (от 6 до 32 символов)
- Выбор типов символов: цифры, буквы, специальные символы
- Копирование пароля в буфер обмена
- Сохранение истории генерации в JSON-файл
- Просмотр последних 10 сгенерированных паролей
